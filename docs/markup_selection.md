# Как выбирается разметка видео

У видео бывает два варианта разметки:

| Вариант | Где лежит | Для чего |
|---|---|---|
| **Рядом с видео** | `<папка видео>/<имя видео>.markup.json` | своя разметка конкретного видео |
| **Боевая** | `<каталог боевых JSON>/<ключ>.json` | общая разметка, которой пользуется рабочая система |

Если есть разметка рядом с видео, по умолчанию показывается она, иначе — боевая.

## Ключ боевой разметки

Ключ — имя файла в каталоге боевых JSON без `.json`: для `line1_cam5.json` ключ `line1_cam5`.
Каталог плоский: файлы лежат прямо в нём, подкаталоги не просматриваются.

Ключ для видео выбирается по порядку, первое найденное побеждает:

1. **Выбран вручную.** Пользователь выбрал файл для этого видео («Открыть файл…» в карточке видео).
   Файл должен лежать в каталоге боевых JSON. Выбор можно отменить — «Подбирать автоматически».
2. **Задан приложением-хозяином.** Приложение, в которое встроена библиотека, вернуло ключ
   из `MarkupLabHost.markup_key(video)` (например, по своей базе или своему правилу имён).
3. **Подобран по каталогу** — по правилам ниже.

Если ключ не найден, боевая разметка недоступна, а в подсказке указана причина.

## Подбор по каталогу

Имя файла разметки и путь к видео делятся на **части** по разделителям `/ \ { } - _ . пробел`.
Регистр букв не важен, части сравниваются целиком.

Файл **подходит** видео, если каждая его часть найдена:

- сначала в имени видео;
- если там нет — в папках над видео, начиная с ближайшей.

Пример: видео `D:/video/site_a/day1/line1_cam25_0101_1310.avi`.

| Файл в каталоге | Части | Результат |
|---|---|---|
| `site_a_cam25.json` | `site`, `a`, `cam25` | `cam25` — в имени, `site` и `a` — в папке `site_a` → подходит |
| `site_a_cam2.json` | `site`, `a`, `cam2` | `cam2` ≠ `cam25` → не подходит |
| `line1_cam25.json` | `line1`, `cam25` | обе части в имени видео → подходит |
| `site_b_cam25.json` | `site`, `b`, `cam25` | `b` не найдено → не подходит |

Если подходят несколько файлов, побеждает тот, у которого:

1. больше частей найдено в **имени видео** — имя видео важнее папок;
2. больше частей всего — более точное имя файла;
3. остальные части найдены в папках **ближе** к видео;
4. есть часть с **производством** видео — если приложение-хозяин передало список производств
   (`MarkupLabHost.factories()`); производство видео ищется сначала в имени, затем в папках.

В примере выше подходят `site_a_cam25` и `line1_cam25`. У `line1_cam25` в имени видео найдены две части,
у `site_a_cam25` — одна, поэтому выбирается `line1_cam25.json`.

Если лучших файлов несколько и правила их не различают, разметка **не выбирается**:
в подсказке перечислены кандидаты, файл нужно выбрать вручную или задать правилом приложения-хозяина.

Что не участвует в подборе:

- скрытые файлы (имя начинается с точки);
- файлы разметки рядом с видео (`*.markup.json`);
- файлы не `.json`.

## Данные приложения-хозяина

```python
from pathlib import Path
from neuro_markup_lab import MarkupLabHost


class Host(MarkupLabHost):
    def markup_key(self, video: Path) -> str | None:
        """ Ключ боевой разметки видео; None — подобрать по каталогу. """
        return my_rule(video)

    def factories(self) -> list[str]:
        """ Известные производства: помогают выбрать между равными файлами. """
        return ["site_a", "site_b"]
```

Все методы необязательны: переопределяется только то, что приложение знает.
Методы вызываются на каждый запрос, поэтому данные всегда актуальны.
